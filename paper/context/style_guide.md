# Style guide for paper drafting

## Target format

Final deliverable per section is LaTeX, written to be pasted directly
into an Overleaf project. Draft in plain prose first (markdown is fine
for iteration), convert to LaTeX only once the content is settled, since
fixing wording is harder to review inside `\citep{}` and `\begin{}` noise.

Confirm the target venue and its LaTeX class before final formatting.
Given this project extends Cau et al. (2025), *EPJ Data Science*
(Springer Nature) is the natural default target, which uses the
`sn-jnl` document class, but this has not been confirmed with Rossetti.
Ask before assuming. Until confirmed, draft in plain `article` class so
nothing has to be redone, only reformatted.

## Writing rules, non-negotiable

No em dashes anywhere. No "delve," "leverage," "robust," "seamless,"
"it's important to note," "in order to," "a testament to," "boasts,"
"unlock," or similar AI-writing tells. No filler openers ("In this
section, we will...") or filler closers ("In conclusion..."). State the
first real fact immediately; end when the last real fact is given.

Active voice throughout. "We ran the ablation across four conditions,"
not "The ablation was run across four conditions."

One claim per sentence where possible. Do not chain two independent
claims with "and" when each deserves its own sentence and its own
citation.

Every empirical claim needs a source: either a citation from
`related_work_sources.md`, a specific number from a results report under
`reports/`, or a specific file/line reference into the codebase for a
methodology claim. A sentence with no traceable source behind it does not
get written, full stop, regardless of how plausible it sounds.

Hedge honestly. "tom_only shows a flatter acceptance curve" is a claim
that needs data behind it. "tom_only is expected to show a flatter
acceptance curve" is a hypothesis statement and must be marked as such
if the data is not yet in hand.

## Section-specific notes

**Methodology**: written entirely from `methodology_facts.md`. Do not
add mechanism details not present there without re-reading the actual
source file first and updating that document.

**Related work**: written entirely from the Confirmed tier of
`related_work_sources.md`. If a citation is needed and it is not there
yet, stop and source it properly rather than writing around the gap with
vague unattributed claims ("prior work has shown...").

**Results**: not drafted until the underlying ablation numbers exist in
a `reports/*.md` file. No placeholder numbers, no illustrative examples
presented as if real.

## Review pass before anything is considered done

Run the content through the project's avoid-ai-writing skill (or an
equivalent manual pass) before treating a section as finished. A section
that reads like it could have been generated by any model about any
paper has failed this pass, regardless of factual accuracy.
